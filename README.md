# Jeopardy Amigos

A single-file Jeopardy-style trivia game for a group of friends (video games, Pokémon, football, music, movies & series, internet & memes, food & drinks). English and Spanish, 2–6 teams, multiple question types (multiple choice, true/false, higher/lower, closest number).

## Play
Open `index.html` in any browser. To host it free: GitHub repo → Settings → Pages → deploy from the `main` branch, root folder.

## Notes
- Default teams are Team 1–4; rename them in the start menu.
- Use **Save / Load** to export or import your board as a JSON file.
- The AI question generator only works inside Claude and is inactive here.
